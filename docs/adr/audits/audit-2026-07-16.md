### Sugeridas

**ADR-004 — Uso de Playwright para pruebas E2E**
- **Qué medir:** que no se agregue como dependencia un framework E2E alternativo (Cypress, TestCafe, WebdriverIO).
- **Herramienta sugerida:** script Node que inspeccione `package.json` (mismo patrón que `scripts/check-app-router-only.mjs`).
- **Esbozo:** fallar si `dependencies`/`devDependencies` contienen `cypress`, `testcafe`, `webdriverio`, etc.

**ADR-005 — Quality Gate shift-left**
- **Qué medir:** que cada etapa declarada (lint, formato, tests+cobertura, husky, lint-staged, e2e, sonar) siga configurada y wireada.
- **Herramienta sugerida:** script Node de verificación de "manifiesto" del pipeline.
- **Esbozo:** comprobar la existencia de los scripts `lint`/`format:check`/`test:coverage`/`test:e2e`/`sonar` en `package.json`, de `.husky/pre-commit` y `.husky/pre-push`, de `.lintstagedrc.json` y de `sonar-project.properties`.

**ADR-008 — Tailwind CSS como framework de presentación**
- **Qué medir:** que no se agreguen librerías de estilos alternativas.
- **Herramienta sugerida:** script Node sobre `package.json`.
- **Esbozo:** fallar si aparecen `styled-components`, `@emotion/*`, `bootstrap`, etc.

**ADR-009 — Base UI como librería de componentes**
- **Qué medir:** que no se agreguen librerías de componentes UI alternativas.
- **Herramienta sugerida:** script Node sobre `package.json`.
- **Esbozo:** fallar si aparecen `@mui/material`, `antd`, `@chakra-ui/react`, `react-bootstrap`, etc.

**ADR-010 — Zustand para manejo de estado**
- **Qué medir:** que no se agreguen librerías de estado global alternativas.
- **Herramienta sugerida:** script Node sobre `package.json`.
- **Esbozo:** fallar si aparecen `redux`, `@reduxjs/toolkit`, `mobx`, `recoil`, `jotai`, etc.

**AGENTS.md §Reglas generales — Nombres en inglés**
- **Qué medir:** que identificadores y rutas no contengan palabras comunes en español o caracteres no-ASCII (heurística, no garantiza "es inglés" al 100%).
- **Herramienta sugerida:** regla ESLint (`id-match`/regla custom) o script Node sobre `src/**`.
- **Esbozo:** fallar si un identificador/ruta contiene caracteres no-ASCII (`ñ`, tildes) o coincide con una lista de palabras españolas comunes.
